# Keyboard shortcuts

These are the default shortcuts. Each is shown as Ctrl on Windows and Linux with the Mac key in parentheses. You can rebind any of them in the **Composer** tab of your settings (see [Composer and keyboard settings](/guide/composer-settings)).

## Navigation

| Action             | Keys                         | What it does                                                                                                 |
| ------------------ | ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Quick Switcher     | Ctrl+K (⌘K on Mac)           | Open the stream picker. See [Quick switcher and command palette](/guide/quick-switcher-and-command-palette). |
| Commands           | Ctrl+Shift+K (⌘⇧K on Mac)    | Open the command palette.                                                                                    |
| Sidebar Quick Jump | Ctrl+1 to 9 (⌘1 to 9 on Mac) | Hold the modifier to see numbers on the first nine streams in the sidebar, then press a digit.               |
| Next Stream        | Alt+Shift+Down (⌥⇧↓ on Mac)  | Open the stream below in the sidebar.                                                                        |
| Previous Stream    | Alt+Shift+Up (⌥⇧↑ on Mac)    | Open the stream above in the sidebar.                                                                        |
| Back               | Ctrl+[ (⌘[ on Mac)           | Go back in stream history.                                                                                   |
| Forward            | Ctrl+] (⌘] on Mac)           | Go forward in stream history.                                                                                |
| Search in Stream   | Ctrl+F (⌘F on Mac)           | Search messages in the current stream. Not available in threads or drafts.                                   |
| Search             | Ctrl+Shift+F (⌘⇧F on Mac)    | Open search. See [Search basics](/guide/search-basics).                                                      |
| Browse Files       | Ctrl+Shift+A (⌘⇧A on Mac)    | Open the attachment explorer.                                                                                |
| Agent Agenda       | Ctrl+Shift+O (⌘⇧O on Mac)    | Open follow-ups and delegated tasks. See [The Agent agenda](/guide/agent-agenda).                            |
| Copy Link          | Ctrl+Shift+L (⌘⇧L on Mac)    | Copy a link to the focused stream or thread.                                                                 |

## View

| Action         | Keys               | What it does                                                                                                                      |
| -------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| Settings       | Ctrl+. (⌘. on Mac) | Open settings.                                                                                                                    |
| Toggle Sidebar | Ctrl+§ (⌘§ on Mac) | Show or hide the sidebar.                                                                                                         |
| Settle         | E                  | Settle the hovered Inbox row, or the open stream if it is in your Inbox. It doesn't fire while you type, or in dialogs and menus. |

## Editing

| Action        | Keys                      | What it does                                                                                                                                               |
| ------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bold          | Ctrl+B (⌘B on Mac)        | Bold the selection.                                                                                                                                        |
| Italic        | Ctrl+I (⌘I on Mac)        | Italicize the selection.                                                                                                                                   |
| Strikethrough | Ctrl+Shift+S (⌘⇧S on Mac) | Strike through the selection.                                                                                                                              |
| Inline Code   | Ctrl+E (⌘E on Mac)        | Format the selection as inline code.                                                                                                                       |
| Code Block    | Ctrl+Shift+C (⌘⇧C on Mac) | Insert a code block.                                                                                                                                       |
| Save Draft    | Ctrl+S (⌘S on Mac)        | Stash the current composer content into your saved drafts and clear the editor. See [Drafts and scheduled messages](/guide/drafts-and-scheduled-messages). |

Editing shortcuts apply when the composer is focused. For formatting, see [Formatting](/guide/formatting).

## Change a shortcut

Click the key badge for an action in the **Composer** tab and press the new combination. A changed shortcut shows a reset button that restores its default, and **Reset all shortcuts** appears once you have changed any. If the combination is already taken, you can move it to the new action.
