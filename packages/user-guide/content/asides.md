# Asides: a private side-chat with Ariadne

An aside is a private page beside the conversation you are reading. You think out loud with Ariadne there, or write a draft, and nothing reaches the conversation until you send it yourself.

## Open one

- Select **Aside** in the stream header. On a phone it is an icon without the word.
- Run **Open an aside here** from the command palette. See [Quick switcher and command palette](/guide/quick-switcher-and-command-palette).
- Type `/aside` in the composer.
- Choose **Open an aside here** from a message's menu, to anchor the aside to that message.

Asides can be opened in channels, DMs, scratchpads and threads. They can't be opened in an archived stream, in an end-to-end encrypted stream, or inside another aside.

When you open one, Ariadne can see what was on screen at that moment, so you can ask about the conversation without pasting it. An aside is titled automatically.

## Who sees it

Only you. An aside is private even inside a public channel, and others in the conversation never see its contents. It is always a Companion conversation with Ariadne. Memory is off for asides, so nothing in them is saved as memos. An aside is always muted; it has no notification levels to choose from.

## Find it again

In the timeline, a row marks where the aside was opened, anchored to a message when you started it from one. The row has a **Resume** button, or **Open** while the aside is showing. The header button follows the aside's state: grey while idle or while Ariadne is working, and highlighted when the aside is open, or when she has answered since you last looked, in which case it reads **New reply**. Select it to resume the newest aside on that stream. Asides never get a sidebar row, and they don't appear on the Streams page.

Inside an aside, a line at the top shows what it is anchored to, and selecting it jumps back to the original message.

## Drafts

An aside can hold drafts. Select **Start a draft** (or the plus button once you have some) to open an editor with the full formatting toolbar. Drafts are kept as pills above the chat, each showing its age and an X to delete it.

- **Send to composer** moves the draft into the composer of the conversation the aside sits beside. You still review and send it there.
- On a message from Ariadne in an aside, **Insert into draft** adds it to your draft as an attributed block.

## Asides and threads

A thread is shared: everyone in the stream can open it and reply. An aside is yours alone, always includes Ariadne, and is never counted as a reply to the message it was opened from. Use a thread when others should take part, and an aside to work something out before you post. See [Threads](/guide/threads).
