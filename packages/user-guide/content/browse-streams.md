# Browsing all streams

The [Streams](app:streams) page lists every channel, scratchpad, DM and thread you can reach, including public channels you haven't joined. Open it from the **Streams** quick link in the sidebar, from **Browse streams** in the sidebar's menus, or from **Browse Streams** in the command palette. **Browse scratchpads** in the Scratchpads add menu opens the page on the Scratchpads tab.

## Tabs

The page has tabs for **All**, **Channels**, **Scratchpads**, **DMs** and **Threads**. Each tab has its own address, so a link or a refresh returns to the same tab.

## Finding a stream

- **Search streams** filters by name.
- **Joined** and **Not joined** narrow the list to streams you are in or not in.
- **Sort** orders by Recent activity (the default), Name or Members.
- **Archived** switches to archived streams. Search then reads "Search archived".
- The Threads tab can be narrowed to one stream's threads, for example from the **Threads** link on a stream's hover card. A chip showing that stream's name with an x clears the filter.

At the top of the list, a **Most active** strip shows up to four streams with the most messages over the last 14 days. Streams with no messages in that period don't qualify. The strip is hidden while you search and in the archived view.

## Reading a row

A row shows the stream's name, a lock icon for private channels, an unread badge, the type and when you joined, a preview of the last message and how long ago it was sent. It also shows a small activity chart for the last 14 days and the member count. The chart is hidden on narrow screens, and member avatars show on desktop only. On desktop, hovering a row shows a card with more detail. A thread row says which stream it is in.

## Joining

Public channels you aren't in have a **Join** button on their row. If joining fails, a message names the channel. Selecting the row opens the channel without joining, where a **Join Channel** bar appears. See [Channels](/guide/channels).

## What is not listed

System streams and asides never appear here. Threads under an archived stream are sealed and don't list as active.
