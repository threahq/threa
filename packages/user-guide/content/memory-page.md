# The Memory page

The [Memory](app:memory) page lists the memos Threa has saved from your conversations. Open it from the sidebar, or choose **Search memory** on the [Search](app:search) page once you have typed search words, to run them here.

## Find a memo

Type in **Search workspace memory...** to search memos. The count at the top shows how many memos match (it is hidden on a phone). The refresh button reloads the list.

Filters sit under the search box:

- A stream picker, labelled **All streams** until you choose one.
- The memo type, shown as **All types** until you choose Message or Conversation.
- The knowledge type, shown as **All knowledge** until you choose Decision, Learning, Procedure, Context or Reference. See [How Threa remembers](/guide/how-memory-works) for what each means.
- Status: **Active** (the default), **Archived** or **Superseded**.
- A scope filter, **All memory** by default. Choose **About you** to list only your private memos.

**Clear filters** appears once any filter is set. Your search, filters and selected memo are kept in the page address, so a refresh or a shared link shows the same view.

Each result shows the title, the start of the abstract, the knowledge type, up to two tags and the stream it came from. An arrow button on each result shows its source messages in place (**Show source messages**).

## Read a memo

Select a result to open it on the right, or in a drawer on a phone. The memo shows:

- The knowledge type, the memo type, its status, and **About you** or an agent badge where they apply.
- The title, abstract and tags.
- **Key points**.
- **Provenance**: links to the stream it came from.
- **Source messages**: the messages it was built from, each linking to the message in its stream.

A superseded memo links to its replacement with "Replaced by a newer memo". **Copy link** copies a link to the memo.

## Correct or retire a memo

On an open memo:

- Choose **Edit** to change the title, abstract, key points (one per line) and tags, then **Save**.
- Choose **Archive** to set an active memo aside. On an archived memo, **Restore** brings it back.
- **Delete** appears only on **About you** memos. It asks for confirmation and cannot be undone. Memos shared with other people can be archived but not deleted.

In a conversation, the "Saved to memory:" line links to the same memos. A memo preview there has an **Open in memory** button that opens it on this page.
