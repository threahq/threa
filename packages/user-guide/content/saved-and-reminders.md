# Saved messages, to-dos and reminders

Saving a message puts it on your private [Saved](app:saved) page so you can come back to it. You can attach a reminder to a saved message, or add a to-do that isn't tied to any message.

## Save a message

On desktop, hover a message and click the bookmark button. Clicking it again removes the item. Hovering the button opens a small panel with reminder options, **Mark done**, **Archive** and **Remove**. Once an item is done or archived, the panel also offers **Move back to Saved**.

The message menu has the same actions:

- **Save for later** saves the message. It disappears once the message is saved.
- **Set reminder…** saves the message if needed and asks when to remind you.
- **Remove from Saved** removes the saved item.

Saving a message that you already marked done or archived brings it back to the **Saved** tab.

## Set a reminder

Pick a preset (**In 15 minutes**, **In 1 hour**, **In 3 hours**, **Tomorrow morning**, **Next week**), **Custom duration…**, or **Pick a time…** for an exact date and time. **Clear reminder** removes it. A time in the past is treated as now. **Tomorrow morning** and **Next week** follow your work schedule.

When the reminder fires, it appears in your [Activity](app:activity) feed as "Reminder for message in" the stream (a to-do reminder reads just "Reminder" with the title), and you get a push notification if you have them on. The saved item then shows "reminded". Marking an item done or archiving it cancels a pending reminder.

## Add a to-do

A to-do is a saved item with a title and no message. There are two ways to add one:

- On the **Saved** tab, type in the **Add a to-do…** box and press Enter or the plus button (**Add to-do**). Titles can be up to 300 characters.
- In the command palette, run **Add To-do**, type the title at the "What needs doing?" prompt and press Enter.

Each item on the **Saved** tab has a bell button (**Set reminder**) with the same options, so reminders work on to-dos too. The pencil button (**Edit to-do** for a to-do, **Edit note** for a saved message) lets you change the title or add notes.

## The tabs

- **Saved** holds items you still need to deal with.
- **Suggested** holds to-dos Threa noticed in your conversations. Each shows where it came from and, when there is one, a due date. **Add** moves it to Saved. **Dismiss** removes it. Nothing reaches your list unless you add it.
- **Done** holds items you marked with **Mark done**.
- **Archived** holds items you put away with **Archive**.

On the Done and Archived tabs, **Restore to saved** moves an item back. On every tab, **Remove saved item** deletes it. Each saved message shows the stream it came from. If the original message was deleted, the item is tagged "deleted" and says "Original message was deleted". If you can no longer see the stream, it is tagged "no access" and says "You no longer have access to this message".

Saved items are visible only to you. Drafts and scheduled sends are on separate pages, covered in [Drafts and scheduled messages](/guide/drafts-and-scheduled-messages).
