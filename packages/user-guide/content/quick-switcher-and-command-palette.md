# Jump anywhere with the quick switcher

The quick switcher is a search box for your streams and for Threa's commands. Open it with Ctrl+K (⌘K on Mac), or from the command icon in the sidebar header, whose menu has **Jump to stream**, **Commands** and **Browse streams**.

## Stream search

The default mode, **Stream search**, finds scratchpads, channels and direct messages by name. The results list shows each stream's type, and marks public channels you haven't joined with "Not joined". Select a result, or press Enter on the first one, to open it.

- People you have no direct message with yet appear under **Users**. Selecting one starts a conversation.
- Threads are left out until you type a query, so the unfiltered list stays a list of places to go. A thread result names the stream it lives in.
- Your own asides appear here too. Selecting one opens its host stream with the aside open.
- **Add filter** narrows results by **Stream type** or **Status** (Active or Archived), so you can find archived streams.

When nothing matches, the list says "No streams found."

## Command palette

Type `>` at the start of the box, or pick the **Command palette** tab, to switch modes. Press Ctrl+Shift+K (⌘⇧K on Mac) to open the switcher straight in command mode, which is the sidebar's **Commands** item. The placeholder reads "Run a command..." and an empty result says "No commands found."

### Commands for the stream in view

When a stream is open, a group named after it comes first. It includes, depending on the stream:

- **Settle**, when the stream is in your Inbox.
- **Create snippet**.
- **Open an aside here**, when the stream can host one.
- **Open stream settings**.
- **Browse files in this stream**.
- **Agent agenda in this stream**.
- **Labels…**.
- **Archive this stream** or **Unarchive this stream**, only if you created the stream (or the channel a thread belongs to).

An unsent draft scratchpad only offers **Create snippet** and **Delete this draft**.

### Commands everywhere

The **Commands** group holds the rest:

- Create: **New Post**, **New Scratchpad**, **New Quick Note**, **New Encrypted Scratchpad**, **New Encrypted Quick Note**, **Add To-do** and **New Channel**. **Add To-do** asks for a title and saves it to [Saved](app:saved).
- Go to: **Search messages**, **View Board**, **View Drafts**, **View Saved**, **Browse Streams**, **Browse files**, **View Agent Agenda**, **View Scheduled**, **Open Memory**, **View Labels** and **View Activity**.
- Settings: **Open Settings**, one **Settings:** entry per settings tab (Diagnostics only where it's available to you), **Workspace Settings** and **Invite People**, which opens the Users tab of workspace settings.
- **AI Agents settings**, shown to workspace admins only.

Typing narrows the list, and it matches more than the label. "bookmark" finds **View Saved**, for example.

## Other ways to move around

Hold Ctrl (⌘ on Mac) to number the first nine sidebar streams, then press a digit to open one. Back and Forward are Ctrl+[ and Ctrl+] (⌘[ and ⌘] on Mac). All shortcuts can be changed, see [Keyboard shortcuts](/guide/keyboard-shortcuts).
