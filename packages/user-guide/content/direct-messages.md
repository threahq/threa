# Direct messages

A direct message (DM) is a private conversation between you and one other person. DMs are always private and can't have members added.

## Start a DM

- Open the quick switcher with Ctrl+K (⌘K on Mac) and pick a person from the **Users** group. Entries for people you have no DM with yet read "Direct Message · Start conversation".
- Open someone's profile and select **Message**.
- Pick them from the sidebar, which also lists people you haven't messaged yet.

The conversation is created when you send the first message. Until then it is an empty draft.

## Profiles

Select a person's name or avatar on a message, a user @mention, or a quoted reply to open their profile. In a DM, select the person's name in the header. On mobile, open the stream sheet and choose **View profile**.

A user profile shows:

- Their avatar, name and pronouns
- Their status, with an emoji, text and when it clears
- An **Owner** or **Admin** badge, if they have one
- Their description, and phone number, GitHub username and timezone when they have set them

On someone else's profile you also get a **Message** button, which opens your existing DM or starts a new one. Your own profile is edited under [Profile settings](/guide/profile-settings).

## Bot profiles

Selecting a bot as an author opens a bot profile instead. It shows:

- Its name and @handle, and whether it is **Personal** or **Shared**. A personal bot names the person who owns it.
- Its description and traits
- What it can read. A shared bot reads only the streams it is added to. A personal bot's owner sees that it reads everything they can read, except end-to-end encrypted streams.
- For bots backed by a runtime, whether it is Available, Busy, Offline or in Error, and when it was last seen
- The streams it belongs to, as links

People who can manage the bot also get a **Manage** button that opens its settings. See [Bots overview](/guide/bots-overview).

## Calling from a profile

When calls are on in your workspace, someone else's profile has a **Call** button that starts a video call in your DM with them. It is disabled until the two of you have a DM, with the hint "Send a message first to start a call", and while you are already in a call. See [Starting and joining calls](/guide/calls-basics).

## Notifications

DMs notify you for every message by default. In the DM's settings you can switch that to Muted. See [Stream settings](/guide/stream-settings).
