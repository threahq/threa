# Editing, deleting and revisions

You can edit or delete your own messages. Every edit keeps the earlier version, so anyone who opens an edited message can read its history.

## Edit a message

Choose **Edit message** from the message menu, or press the up arrow in an empty composer to edit your most recent message in that stream. The message turns into an editor in place.

- Click **Save** or press Ctrl+Enter (⌘Enter on Mac) to save. On desktop, Enter saves too. Esc or **Cancel** leaves without saving. On a touch screen, the editor opens in a drawer, and Enter adds a new line.
- The expand button below the editor, labeled **Expand editor**, opens a larger editor for long messages.
- If you save without changing anything, nothing happens.
- If you clear the whole message and save, Threa asks whether to delete it instead.
- If the save can't reach the server, you get an "Edit queued" notice and the edit is sent once you are back online.

Only the author can edit a message, and only messages written by a person, not by an agent. Edit is not available in encrypted streams, so there you delete the message and send a new one.

## See revisions

An edited message shows **(edited)** after its text. Click it, or choose **See revisions** from the message menu, to open **Edit history**. The dialog lists each version with its time, including the **Current** one, and shows the text of the one you select. The list is labeled "Revision 1", "Revision 2" and so on on desktop, and "v1", "v2" and **Current** on a phone.

## Delete a message

Choose **Delete message** from the message menu. Threa asks "Are you sure you want to delete this message? This action cannot be undone." and deletes it when you click **Delete**. Only the author can delete a message.

A deleted message leaves a line in the timeline that reads "This message was deleted". Other places that point to it, such as a shared card, say "Message deleted by author".

Quotes and shares of a message you later edit keep showing the version that was quoted or shared. A shared card adds an **Edited since** link. See [Quoting and sharing messages](/guide/quoting-and-sharing).
