# Installing Threa as an app

Threa is a web app that your browser can install, so it opens from the home screen, dock or app launcher in its own window.

## How to install

Threa has no install button of its own. Use your browser's install option: an install entry in the address bar or browser menu on desktop, or **Add to Home Screen** on phones. The wording and location differ between browsers.

## What the installed app does

Threa's app manifest asks for the following:

- It is named Threa and opens in a standalone window, without the browser's address bar and tabs.
- Links to Threa open in the installed app when your system supports that.
- Opening the app while it is already running brings the existing window forward and navigates in it, instead of starting a second copy.
- On systems that support it, Threa is added to the system share menu, so you can send text, links and files into Threa from other apps. See [Sharing into Threa from your phone](/guide/share-to-threa).

## Check whether you are running the installed app

Open [App status](app:app-status). Under **Device readiness**, **Running as** reads **Installed app** or **Web browser**. The same page shows which version you are running and whether an update is ready. See [Updates, offline use and App status](/guide/updates-offline-and-app-status).
