# Drafts and scheduled messages

Threa saves what you type in a composer as a draft, so leaving a stream does not lose it. You can also set a draft aside to start a new message, or schedule a message to send at a later time.

## Drafts

A draft is saved shortly after you stop typing, and it is removed when you send the message or empty the composer. The [Drafts](app:drafts) page lists every unsent draft in the workspace. Select a row to go to that stream with the draft in its composer. Use **Select** to pick several drafts and delete them together. Deleting asks you to confirm with **Delete this draft?**.

### Set a draft aside

Press Ctrl+S (⌘S on Mac) in the composer to save the current text as a draft and clear the editor. In an empty composer, the same shortcut opens the list of saved drafts. The **Drafts** button in the composer opens the list of saved drafts. **Save current** in that list does the same as the shortcut. On a phone, **Drafts** is a row in the **+** menu next to the composer. Select a saved draft to bring it back, or use **Delete saved draft** to throw one away. Drafts that were set aside show as **Stashed** on the Drafts page.

## Scheduled messages

Write the message, then open the **Scheduled** button next to the send button and choose **Schedule send**. On a phone, use the **Schedule** row in the **+** menu. Pick one of:

- **In 15 minutes**, **In 1 hour** or **In 3 hours**
- **Tomorrow morning** or **Next week**
- **Custom duration…**
- **Pick a time…**, with a date and a time, then **Schedule**

The same button lists the messages scheduled for the current stream. Scheduling needs a message in the composer.

### The Scheduled page

The [Scheduled](app:scheduled) page has two tabs.

- **To send** lists messages waiting to go out. Each one can be sent with **Send now**, changed with **Edit**, or removed with **Cancel**.
- **Sent** lists messages that have been delivered. Select one to open the message in its stream.

While the edit dialog is open, the message is held back from sending for up to ten minutes. See also [Saved messages, to-dos and reminders](/guide/saved-and-reminders).
