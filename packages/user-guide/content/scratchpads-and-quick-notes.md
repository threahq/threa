# Scratchpads and quick notes

A scratchpad is a conversation that belongs to you alone. [Your first scratchpad](/guide/your-first-scratchpad) covers creating one; this article covers how it behaves afterwards.

## Scratchpad or channel

- A scratchpad is always private. Its visibility can't be changed, and you can't add other people to it.
- A channel has members, can be public, and has a name that works as a handle. See [Channels](/guide/channels).
- A scratchpad has a companion mode: Ariadne is on in a Scratchpad and off in a Quick Note.

## Drafts until you send

New Scratchpad and New Quick Note create a draft that exists only in your browser. The header shows it as "(draft)" and it appears on the [Drafts](app:drafts) page. The scratchpad is created on the server when you send the first message. Before that, you can change the companion mode and the other settings that appear in the header, and they are carried into the new scratchpad.

To discard a draft, run **Delete this draft** from the command palette or the quick switcher and confirm. See [Quick switcher and command palette](/guide/quick-switcher-and-command-palette).

The New Encrypted Scratchpad and New Encrypted Quick Note commands skip the draft step and are created on the server straight away.

## Naming

A scratchpad is named from what you write first. To change the name, click the title in the header, or open the **Stream actions** menu and choose **Rename**. When the name was set by hand, or predates automatic titles, the scratchpad's settings also offer **Regenerate title**.

## The mode pill

The pill in the header shows how Ariadne is set up in this scratchpad: **Companion**, **Quiet**, **External** when an outside agent is attached, or just a lock icon for an encrypted scratchpad. Select it to open a popover with the companion mode. As the scratchpad's owner you can also restrict which tool groups Ariadne may use. On mobile the same controls are in the stream sheet.

The full set of options is on the Companion tab, described in [Stream settings](/guide/stream-settings).

## Add To-do

Add To-do is a command palette entry. It asks "What needs doing?" and saves your answer to [Saved](app:saved). It does not create a scratchpad, and it is not a note. Quick Notes are scratchpads; a to-do is a saved item.

## Other actions

The **Stream actions** menu (the three dots in the header) also offers Settings, Labels…, Copy link, Move messages…, Browse files…, Agent agenda…, Rename and Archive (Unarchive once archived). Move messages… isn't offered on an archived scratchpad. Archiving hides the scratchpad from the sidebar, and you can unarchive it later. Archived streams are listed on the [Streams](app:streams) page under **Archived**.
