# Writing and sending messages

The composer is the box at the bottom of every stream. It is a rich text editor: you can format text, mention people, attach files and run commands from it.

## Sending

With a mouse and a wide window, **Enter** sends the message and **Shift+Enter** starts a new line. **Ctrl+Enter** (⌘Enter on Mac) always sends.

You can change this in the **Composer** tab of your settings. Under **Send Messages**, choose **Enter to send** or **⌘/Ctrl + Enter to send**. With the second option, Enter starts a new line and only the modifier combination sends.

The send mode is fixed in two places:

- On a phone, a tablet or any touch-first device, and in a window narrower than 640 px, Enter always starts a new line. Use the **Send** button.
- In the fullscreen editor, Enter always starts a new line. Use **Send** or Ctrl+Enter (⌘Enter on Mac).

If an upload failed, the Send button is disabled until you remove it. Its tooltip says "Remove failed uploads before sending".

## The action bar

Below the text are the buttons for everything else:

- **Formatting** (the **Aa** button) shows or hides the formatting toolbar. See [Formatting text](/guide/formatting). On desktop the bar also reads "Select text to format", because selecting text brings up a floating toolbar.
- **Emoji**, **Mention** and **Command** insert a `:`, `@` or `/` and open the matching picker. See [Mentions and channel links](/guide/mentions-and-links) and [Slash commands](/guide/slash-commands).
- **Attach files** opens a file picker. See [Attachments and the Files page](/guide/attachments-and-files).
- **Expand editor** opens the fullscreen editor.

On a phone the bar is different. **Attach files**, **Open an aside**, **Schedule**, **Drafts** and **Expand editor** sit in a **More** (+) menu, and there **Expand editor** grows the composer in place instead of opening the dialog described below.

There is also a microphone for [dictation](/guide/voice-dictation), a drafts button and a schedule button; see [Drafts and scheduled messages](/guide/drafts-and-scheduled-messages).

When the composer is narrow, such as in a side panel, some of these buttons move into a **More actions** (+) menu. They do the same thing from there.

## Fullscreen editor

**Expand editor** opens the composer in a large dialog. It is the same composer, so what you have typed carries over, and on desktop the formatting toolbar starts open. **Send** posts the message. **Close editor** (the X) or two presses of Escape close the dialog without sending; the first Escape leaves the text field, the second closes the dialog. The text stays in the composer as a draft. The button is not shown in the composer of an [aside](/guide/asides).

## Composer settings

The **Composer** tab in your [settings](app:settings/keyboard) also holds:

- **Insert files at the cursor**, for the mobile composer: a picked file appears as a chip inside the message. Removing the chip keeps the file attached.
- Keyboard shortcuts for navigation, view and formatting, which you can rebind. See [Keyboard shortcuts](/guide/keyboard-shortcuts).

To move the Send button to the left end of the composer, use the **Composer actions** setting in the **Accessibility** tab.
