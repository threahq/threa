# Signing in and switching accounts

Threa uses WorkOS for sign-in. One browser can hold several accounts at once, so you can move between a work and a personal account without logging out.

## Sign in

Open the login page and select **Sign in with WorkOS**. After you sign in, Threa opens the last workspace you used in this browser. If there isn't one, you land on the workspace picker. See [Creating or joining a workspace](/guide/create-or-join-a-workspace).

## Add another account

Open the user menu at the bottom of the sidebar and select **Switch account**. In the **Switch account** dialog, select **Add account**. The page offers three ways to sign in:

- **Continue with Google**
- **Continue with Microsoft**
- **Continue with email code**

For the email code, enter your address and select **Send code**, then type the 6-digit code from your inbox and select **Verify**. If the code is wrong you see "That code didn't match. Check your email and try again." Use **Use a different email** to start over.

Your current sessions stay parked while you add the new one. A browser holds up to four accounts. At the limit, **Add account** is disabled; remove one to add another.

## Switch between accounts

The **Switch account** dialog lists each account with its name and email. The active one is highlighted and has a check mark. Select any other row to switch to it.

An account whose session has expired shows as **Signed-out account** with the note "Session expired — sign in again". Select **Add an account** on that row to sign in again, or use the remove button next to it.

To take an account out of the browser, use the trash button on its row.

## Log out

Select **Log out** in the user menu. With one account signed in, you are logged out right away. With more than one signed in, a **Log out** dialog asks what to do:

- **Sign out of** followed by the active account's name, which keeps you signed in to the others.
- **Sign out of all accounts**, which signs out of every account on this browser.
- **Cancel**.
