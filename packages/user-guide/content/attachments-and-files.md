# Attachments and the Files page

You can attach files to any message. Everything uploaded to a workspace is listed on the [Files](app:files) page, where you can search it and filter by type, stream, uploader and date.

## Attaching files

- Click **Attach files** in the composer's action bar and pick files.
- Drag files into the editor, or paste them from the clipboard.
- Type **/attachment** to place a file at the cursor. The list shows the files already attached to your draft, plus **Upload a file…**.

A sent attachment can show **Uploading…** and then **Scanning…** in the timeline until it is ready. A file that fails the malware scan is quarantined and shown as blocked. A single file can be up to 100 MB.

On desktop the files sit in a tray above the text. On mobile, files you pick with **Attach files** are placed in the message text as a chip at the cursor, and removing the chip keeps the file attached. The **Insert files at the cursor** switch in the **Composer** settings tab turns that off, and it is on by default. See [Writing and sending messages](/guide/composer-basics).

## Viewing files

Click an attachment in the timeline to open the viewer. Images, videos, PDFs, markdown, HTML and text files all open there. Markdown and HTML files have a toggle between **Show rendered preview** and **Show raw source**. The viewer's toolbar can copy the image, text or source, and download the file.

## The Files page

Open it from the sidebar's **Files** quick link (when shown), with Ctrl+Shift+A (⌘⇧A on Mac), or from the command palette with **Browse files**. The command palette entry **Browse files in this stream** and the stream menu's **Browse files…** open the same list for only the stream you are in.

- The search box matches filenames and the text extracted from files. Put a phrase in quotes for an exact match.
- **Add filter** offers the file types Images, Videos, Audio, PDFs, Documents, Sheets, Slides, Code and Archives. Files of any other kind are classed as Other. It also lists uploaders.
- **Stream** limits the list to chosen streams, **Filename** matches part of a name, and **Date** sets an After and a Before date.

Files are listed newest first, grouped under headings such as Today, Yesterday and This week. Select a file to see its details, an **Extract** of its text where Threa has one, and **Open original**. Agents can read attachments too. See [What agents can do](/guide/what-agents-can-do).
