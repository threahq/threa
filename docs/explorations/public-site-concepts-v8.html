Threa · Public site concepts · v8

Locking in: Threa is a workplace chat app (Slack / Teams shape) with memory built in. Each concept makes that explicit by embedding a real timeline mockup — channel header, user messages, an @ariadne invocation, and her reply using the persona row styling from the app (gold inset stripe, gold gradient, gold name). All shells stay in a single mode (no light/dark mixing) so we can theme the site cleanly. Concept 05 demonstrates the same Spine in dark mode.
